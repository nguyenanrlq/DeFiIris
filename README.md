# DeFiIris

A simple DeFiIris Platform for Real time Processing.

With DeFiIris, you get a lightweight tool that stays out of your way.

**What you get**

- A simple DeFiIris Platform for Real time Processing

## Key Features

- A simple DeFiIris Platform for Real time Processing

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DeFiIris.git`
2. `cd DeFiIris`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DeFiIris, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
